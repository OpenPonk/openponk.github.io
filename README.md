# OpenPonk Website (`openponk.org`)

Static website for the [OpenPonk](https://openponk.org) modeling platform, published via GitHub Pages.

## Maintenance

- Edit `index.html` and static assets directly in this repository (the legacy static-site generator in `openponk.github.io-sources` is deprecated).
- `OntoUML/1.0/` serves the public landing page for the OntoUML 1.0 profile URI (`https://openponk.org/OntoUML/1.0/`).
- The site is the single source of truth for user downloads, supported Pharo versions (`#direct-installation`), contact details, and sponsors.
